# 版本发布说明

这里只记录面向使用者的版本变化；实现细节与完整维护记录见 [CHANGELOG.md](../../CHANGELOG.md)。

## v0.2.2 - 2026-11-13

### 在线更新

稳定版更新现在使用项目专用 Release 发布包，不再在缺少受支持发布资产时回退安装未经校验的源码包。安装前会校验资产大小与 SHA-256；自托管实例可配置公钥并要求 detached signature，缺少或校验失败时会拒绝安装。

管理后台的更新面板会显示发布资产、大小、SHA-256 摘要、更新性质及最低支持版本。CI 在质量检查与构建冒烟通过后创建 Release，并附带具名压缩包、SHA-256 文件和更新元数据；只有配置签名密钥时才附加数字签名。

## v0.2.1 - 2026-11-10

登录页不再公开演示账号口令。冒烟测试创建的公开族谱和社区帖子会在结束时回收，避免测试数据长期出现在公开页面。项目首页补充真实界面截图、开发指南与部署资料。

## v0.2.0 - 2026-11-10

新增适用于自托管实例的在线更新、更新前备份与部署驱动；补充家族统计、疑似重复人物核对和按姓氏检索人物。公开族谱统计遵循在世人物隐私设置。

## v0.1.0

首个版本提供百家姓知识库、家族族谱与关系图谱、称谓计算、档案管理、GEDCOM/CSV/JSON 导入导出、版本快照、宗亲社区和管理后台。
