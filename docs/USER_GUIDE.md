# 用户使用说明

## 1. 开始使用

访问首页 → 「注册」。密码至少 8 位且包含字母与数字，注册时需同意用户协议。登录后进入个人中心；顶部导航可进入百家姓、历史寻根、族谱中心、宗亲社区，顶部搜索框支持中文、拼音全拼/首字母、异体字与繁体字检索。

**开发演示账号**：`demo@xungen.local`，初始口令由 `prisma/seed.ts` 写入（本文档不公开口令）。仅限开发/演示环境，正式部署必须删除或改密。

## 2. 查姓氏与寻根

- **百家姓**：收录《百家姓》通行本全表 **504 姓**（444 单姓 + 60 复姓，按原文序位 1..504 排列，并非现代人口排名）。可用搜索、单姓/复姓、拼音首字母，以及「资料范围」下拉筛选：
  - **含史料出处**（38 姓）：带已审定的起源、异体字、郡望堂号、历史人物、迁徙线索与来源引用，每条史料标注作者、版本、卷次/页码、可信程度与审核状态。
  - **字典型条目**（466 姓）：仅收录可核验的字形、繁体写法、姓氏专用读音与《百家姓》序位，卡片显示「源流待补录」。这类条目**不作任何史实陈述**，得姓源流、历史人物与卷次页码需后续依据真实文献补录，请以平台审定后的条目为准。
  - 列表页顶部的「资料说明」也写明了这一区别；徽章「源流待补录」表示资料尚未补录，不表示已收录的字形或读音有误。
- **历史寻根**：查看古今地名对照与宏观迁徙记录。地图使用本地合规行政区划数据，按 `DOCUMENTED / TRADITION / INFERRED / UNVERIFIED` 着色；传说不会显示为已审定事实。
- **重要**：这里的「历史人物」与你自己录入的「家族成员」完全分开；同姓不会自动认定血缘，也不会自动合并族谱。

## 3. 创建与管理族谱

1. 「族谱中心」→「新建族谱」，填写姓氏、名称、祖籍与可见范围。新建族谱默认是 **PRIVATE（私有）**。
2. 进入族谱工作区，左侧/顶部标签切换：图谱、人物、关系、字辈世代、档案、导入导出、版本、协作、设置。
3. 私有族谱只有协作者可见；匿名访客访问私有对象会被拒绝且不暴露其存在性。

### 人物
新增人物可填写姓名、字号、性别、生卒年、在世状态、可见范围与敏感资料（身份证号等）。**敏感资料以 AES-256-GCM 加密入库**，列表与导出均不返回密文。在世人物即使选择 PUBLIC 也会自动降级为 FAMILY，避免公开在世人员详情。删除进入回收站，可随时恢复。

### 关系
选择两人并指定关系类型（亲子/配偶/收养/过继等）、方向与核实状态。系统会拦截自反关系、重复关系、血缘环、两位以上生物学父母、跨家族自动关联、父母年龄倒挂等，并给出提示。**只有「已核实」的关系默认参与亲属称谓计算**；信息不足时称谓结果显示「无法确定」，系统不会臆测。

### 图谱四种视图
- **纵向世代树**、**横向世代树**、**分支折叠视图**、**时间轴视图**，另有力导向关系网络图。
- 支持滚轮缩放、拖动画布/节点、搜索定位、分支折叠、关系路径高亮、点击节点查看人物详情/称谓/祖先与后代。
- 图谱按视口**局部加载**（单次节点上限 200），不会一次拉全库。

### 字辈、世代与分支
世代与字辈派语由人工录入，默认待审核；系统**不会**根据姓名自动推断世代或字辈。分支可手动创建并挂接成员。

### 版本快照
关键写操作会自动生成版本快照（不含加密敏感字段），也可手动备份。恢复版本需输入 `RESTORE` 显式确认，恢复前系统会自动再备份一次。

## 4. 档案中心

- 上传家谱扫描件、契约、照片、音视频或 GEDCOM/CSV/JSON 文本；服务端校验扩展名、MIME、文件头 magic bytes、体积与文件名。
- 上传文件**不在网站静态目录**，只能通过「下载」按钮经鉴权获取；支持历史版本下载、档案与人物关联、审核状态与可见范围。
- OCR：未配置外部 OCR 服务时会明确提示「未配置」，可改用**人工录入待校对文本**；OCR 结果永不自动创建或核实亲属关系。

## 5. 导入与导出

- **导出**：JSON、CSV、GEDCOM 5.5.1、GEDCOM 7.0、SVG、PNG、PDF 七种格式，均为真实生成的文件；导出不含加密敏感字段。
- **导入**：上传文件后先看到**预览报告**（人数、关系、缺字段、查重与悬空引用冲突），预览阶段**不写数据库**。确认后可勾选跳过某些行，显式提交后才事务写入；导入的关系一律标记为「未核实」，不会自动合并同名人物。

## 6. 协作

所有者可邀请协作者（OWNER / EDITOR / VIEWER），通过邀请链接接受；非协作者看不到协作者邮箱。可随时调整或移除权限。族谱设置里可修改名称、简介、祖籍与可见范围；公开前请确认在世人物与敏感资料已妥善处理。

## 7. 宗亲社区

- 发帖分为寻亲、讨论、活动、家族动态与纠错；可见范围支持公开 / 家族 / 私有。`FAMILY` 帖子只对绑定的家族协作者可见。
- 支持两级评论树、举报/纠错、按类型筛选与关键词检索；私有内容不会因关键词匹配而泄露。
- **同姓宗亲检索**只返回主动开启授权的用户，授权可随时撤回；**分支关联申请需双方分别确认**，确认后也不会生成任何亲属关系。
- 私信与站内通知在个人中心；第三方无法读取他人私信，会话列表不展示邮箱。

## 8. 个人中心与隐私

- 修改资料、隐私授权（宗亲检索、地区展示）、查看在线设备并撤销会话、修改密码（自动撤销其他设备）。
- 导出个人数据 JSON（不含密码哈希、会话摘要、族谱人物明细）。
- 账号注销需密码 + 显式确认，按隐私政策处理个人信息；注销后会话立即失效，原公开内容不再对外展示。
- 隐私政策与用户协议见 `/legal/privacy`、`/legal/terms`，完整功能说明见 `/guide`。

## 9. 管理后台

管理员可查看总览与服务状态、停权/恢复账号与调整角色、处理举报、下架/恢复内容、审定史料与姓氏资料、查看审计日志、修改白名单系统设置。

**边界**：管理员也是普通读者——后台只处理元数据与状态，无法读取私有族谱的人物明细、图谱或导出内容；「同姓自动合并」开关与隐私默认策略不可被放宽。

## 10. 常见问题

| 问题 | 说明 |
| --- | --- |
| 为什么两个人同姓却没有自动关联？ | 同姓不等于同宗，这是平台的硬性数据边界，必须由用户显式录入并核实关系。 |
| 为什么亲属称谓显示「无法确定」？ | 关系链信息不足或关系尚未核实；补全并核实关系后再计算。 |
| 为什么某些史料标注「传说 / 待审核」？ | 可信程度与审核状态如实标注，未审定的资料不会当作事实展示。 |
| 上传的文件为什么不能直接复制链接访问？ | 档案属于私有资料，必须经过鉴权下载接口，防止绕过权限。 |
| 导入后关系为什么是「未核实」？ | 外部文件不能替代家族成员核实；请逐一检查后手动标记核实。 |
| 移动端能用吗？ | 已适配桌面/平板/手机，移动端顶部菜单可展开导航，主要页面无横向溢出。 |

## 11. 数据安全提示

请勿在公开族谱中录入在世人员的身份证号、住址、联系方式等敏感信息。发布前检查人物可见范围、档案审核状态与帖子可见范围。授权（宗亲检索、地区展示）可随时在个人中心撤回。
